# Code of Conduct

This project follows the Contributor Covenant Code of Conduct, version 2.1.

Be respectful, constructive, and specific. Assume good intent, but prioritize
the safety and dignity of contributors when behavior causes harm.

Unacceptable behavior includes harassment, discriminatory language, personal
attacks, doxxing, and sustained disruption of project discussions.

Project maintainers may remove comments, close issues, or block contributors
who violate this code of conduct.

Report concerns to the project maintainer through GitHub.
